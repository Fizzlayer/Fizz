    03 / OPEN API

    Send your own data

    Switch any sensor to API mode. Fizzlayer shows its key once, then accepts JSON readings over HTTPS. Each sensor has its own key so you can rotate or revoke it independently. Copy the sensor_id from its card above.

    curl -X POST https://fizzlayer.com/api/ingest \
  -H 'Authorization: Bearer YOUR_SENSOR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"sensor_id":"YOUR_SENSOR_ID","event_id":"sample-001","metrics":{"temperature_c":27.4}}'
